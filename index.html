📚 Как это работает?

Радужка глаза имеет уникальный узор, который не меняется с возрастом
Мы извлекаем признаки: HOG (градиенты) + LBP (текстура)
Обучаем модель Random Forest различать людей по этим признакам
В реальном времени детектируем глаз через MediaPipe и классифицируем

⚙️ Установка за 2 минуты

# 1. Клонировать репозиторий
git clone https://github.com/ВАШ_НИК/iris-project
cd iris-project

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Собрать данные (минимум 3 человека × 20 фото)
python code/collect_faces.py

# 4. Обучить модель
python code/train_faces.py

# 5. Запустить распознавание
python code/recognize_face.py
